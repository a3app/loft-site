# loft.cx

Сайт продукта **loft** — Loft Overlay For TLS.

Живой адрес: [https://loft.cx](https://loft.cx). Спека и исходники — в [a3app/loft](https://github.com/a3app/loft). Протокол **loft/1.0**. Ссылка `loft://`.

Статический HTML для GitHub Pages. Язык по браузеру (русский, китайский, иначе английский). Порядок переключателя: EN · RU · 中文.

## Просмотр

```
python3 -m http.server 8080
```

Открыть `http://127.0.0.1:8080/`.

DNS у регистратора и записи GitHub Pages — в [README.md](README.md).
